# Arquivos de entrada

Os datasets do desafio não são distribuídos aqui. Para executar sem eles, use `--input examples/encontros.txt` ou uma entrada própria no formato descrito em [Regras de domínio](../docs/dominio.md).

`--dataset N` espera `DataSets/datasetN.txt`; `--all` requer os sete arquivos completos. Quando obtidos pelos meios autorizados, os datasets originais 1–2 e os dois gabaritos permitem executar a suíte completa de 85 testes. O comando de 74 testes dispensa esses dados. [Guia de testes](../docs/testes.md).
