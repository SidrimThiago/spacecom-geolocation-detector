# Diretório de saída

Mantenha este diretório e `gerados/` para executar a CLI e os testes. Cada execução cria um diretório exclusivo em `gerados/`, com os resultados e um manifesto local.

`output1.json` e `output2.json` são **gabaritos externos de teste**, não resultados do detector. Eles não são distribuídos aqui; quando obtidos pelos meios autorizados, devem ficar neste diretório para os testes dos datasets 1–2.
